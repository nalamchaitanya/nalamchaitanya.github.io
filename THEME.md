# Theme provenance

This website uses the AcademicPages theme, a fork of Minimal Mistakes, as used by
[Siyue Liu's website](https://siyueliu112.github.io).

Theme source: <https://github.com/siyueliu112/siyueliu112.github.io/tree/9cb5e0463e9114ef0be4c6cef01af9874a80f0e4>

Vendored files: `_layouts/`, the theme includes in `_includes/`, `_sass/`,
`_data/ui-text.yml`, `assets/css/main.scss`, `assets/js/main.min.js`, and the
Font Awesome fonts in `assets/webfonts/`.

The original MIT license is preserved in `LICENSE`. Font Awesome and bundled
JavaScript retain their upstream license notices. Personal content and photos
from the reference website are not included.

Local adaptations provide Chaitanya's profile, shared biography and publication
data, relative asset paths for local previews, accessible menu labels, and
small responsive layout adjustments in `_sass/_custom.scss`.
